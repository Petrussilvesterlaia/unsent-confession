A two-part unsent micro-confession: a To: line naming who it was meant for, and the message itself, one line written exactly as it was typed and never sent. The program writes it to `/output/entry.txt` for make.fun's "Unsent: The Micro-Confession Sprint" bounty.

## Run it

```sh
python3 -P -s main.py
```
